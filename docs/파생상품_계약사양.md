## 만기일 표시 범위와 확인 사항

- 계산기는 상품별 규칙과 거래소 휴장일 처리를 적용해 당일을 포함한 가장 가까운 최종거래일과 그다음 최종거래일을 표시합니다.
- 공식 일정 공개 범위는 CME 계열·KRX 2026년 말, HKEX·미국 주식옵션 공통 2027년 말이며, 이후 2028년까지의 날짜는 공식 일정 미공개 예상값입니다.
- 가장 이른 공식 일정 공개 범위 종료 2개월 전인 2026년 11월 1일부터 닫을 수 없는 갱신 경고가 계속 표시됩니다.
- 표준 일정은 실제 계약의 상장 여부, 조기 종료 공지 또는 증권사 주문 가능 시각을 보장하지 않습니다.
- `US_STOCK`은 기초 종목이 지정되지 않은 공통 항목이므로 정규 월물만 계산합니다.
- 삼성증권 HTS 사용 시 실제 종목코드, 월물/주간물, 최종거래일, 주문 마감, 반대매매·자동청산 기준을 반드시 다시 확인하세요.

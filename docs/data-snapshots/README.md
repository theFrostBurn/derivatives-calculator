# 증거금 데이터 스냅샷 기록 규칙

이 디렉터리는 기준가격, 위탁증거금률처럼 시점과 증권사에 따라 달라지는 데이터를 증거 자료와 함께 보관합니다. 상품의 승수, 통화, 만기 규칙처럼 비교적 고정적인 계약 사양과 변동 데이터는 분리해 관리합니다.

## 파일 이름

```text
YYYY-MM-DD_증권사_선물증거금.md
```

예시:

```text
2026-08-05_삼성증권_선물증거금.md
```

하루에 여러 번 기록하거나 계좌 유형을 구분해야 한다면 파일명 뒤에 시간 또는 짧은 구분자를 붙입니다.

```text
2026-08-05_153000_삼성증권_선물증거금.md
2026-08-05_삼성증권_일반계좌_선물증거금.md
```

## 필수 메타데이터

각 스냅샷 문서의 맨 위에 다음 항목을 기록합니다.

```yaml
---
asOf: 2026-08-05
broker: 삼성증권
source: 삼성증권 HTS > 메뉴명 또는 화면명
capturedAt: 2026-08-05T15:30:00+09:00
capturedBy: 작성자 또는 수집 방식
accountType: 일반 또는 해당 계좌 유형
marketSession: 장중 또는 장마감
---
```

- `asOf`: 데이터가 적용되거나 화면에 표시된 기준일입니다. 날짜를 알 수 없으면 추측하지 말고 `unknown`으로 기록합니다.
- `broker`: 증거금 기준을 제공한 증권사 또는 청산기관입니다.
- `source`: HTS/MTS 메뉴 경로, 공식 웹페이지 이름 또는 문서 제목입니다. 웹 자료라면 URL도 함께 남깁니다.
- `capturedAt`: 실제로 자료를 확인·캡처한 시각입니다. ISO 8601 형식과 시간대 오프셋을 사용합니다.
- `capturedBy`: 수동 확인, OCR, API 등 자료를 수집한 주체 또는 방식을 식별합니다.
- `accountType`: 전문투자자 여부 등 증거금에 영향을 줄 수 있는 계좌 유형입니다. 알 수 없으면 `unknown`으로 기록합니다.
- `marketSession`: 장중, 장마감 또는 적용 세션을 기록합니다. 알 수 없으면 `unknown`으로 기록합니다.

`asOf`와 `capturedAt`은 다릅니다. 전자는 값의 적용 기준일이고, 후자는 해당 값을 실제로 확인한 시각입니다.

## 상품별 필수 필드

각 상품은 가능한 한 다음 필드를 모두 기록합니다.

| 필드 | 의미 | 예시 |
|---|---|---|
| `productId` | 앱에서 사용하는 고유 ID | `FUTURE_KOSPI200` |
| `productName` | 화면 표시 상품명 | `코스피200선물` |
| `contractMonth` | 조회한 결제월 | `202609` |
| `currency` | 금액 통화 | `KRW` |
| `referencePrice` | 증거금 산정 기준가격 | `1046.81` |
| `initialMarginRate` | 위탁증거금률 | `0.21` |
| `maintenanceMarginRate` | 유지증거금률 | `0.14` |
| `cashMargin` | 반드시 현금으로 충족할 금액 | `unknown` |
| `totalInitialMargin` | 1계약 총 위탁증거금 | `54957525` |
| `maintenanceMargin` | 1계약 유지증거금 | `36638350` |
| `notes` | 예외, 반올림, 화면 표기 설명 | `HTS 표시값` |

비율은 계산하기 쉬운 소수 형식으로 기록합니다. 예를 들어 21%는 `0.21`로 적습니다. 확인되지 않은 값은 빈칸이나 0 대신 `unknown`을 사용합니다.

## 권장 본문 템플릿

```markdown
---
asOf: YYYY-MM-DD
broker: 증권사명

capturedAt: YYYY-MM-DDThh:mm:ss+09:00
capturedBy: manual
accountType: unknown
marketSession: unknown
---

- 캡처 파일: `상대경로/파일명.png`
- 확인 메모: 화면의 기준일 및 적용 시각

## 데이터

| productId | productName | contractMonth | currency | referencePrice | initialMarginRate | maintenanceMarginRate | cashMargin | totalInitialMargin | maintenanceMargin | notes |
|---|---|---|---|---:|---:|---:|---:|---:|---:|---|
| FUTURE_KOSPI200 | 코스피200선물 | YYYYMM | KRW | 0 | 0 | 0 | unknown | 0 | 0 | |

## 검산

- 명목금액 = 기준가격 × 승수
- 위탁증거금 예상값 = 명목금액 × 위탁증거금률
- 유지증거금 예상값 = 명목금액 × 유지증거금률
- 화면 표시값과 예상값의 차이 및 반올림 방식
```

## 기록 및 갱신 원칙

1. 기존 스냅샷을 최신 값으로 덮어쓰지 않고 새 파일을 추가합니다.
2. 원본 화면 캡처나 공식 문서가 있으면 상대경로 또는 URL을 남깁니다.
3. 화면 표시값과 직접 계산한 값을 구분하고 반올림 차이를 기록합니다.
4. 상품 ID는 앱의 상품 정의와 동일하게 유지합니다.
5. 여러 증권사의 값을 섞지 않고 증권사별로 별도 파일을 만듭니다.
6. 증거금률 외에 장중 위험관리 기준이나 추가 증거금 규정이 있으면 출처와 함께 별도 메모로 남깁니다.
7. 앱의 기본값으로 반영할 때는 사용한 스냅샷 파일을 코드나 관련 문서에서 추적할 수 있게 표시합니다.

정확한 기준일이 없는 기존 자료는 새 스냅샷인 것처럼 날짜를 추정하지 않습니다. 필요하면 `asOf: unknown`으로 별도 보존하고, 최신 값을 다시 조회해 새 스냅샷을 작성합니다.

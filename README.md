# 옵션 승수 기반 최소구입금액 계산기

단일 HTML 파일로 동작하는 옵션 계산기입니다. 종목(옵션 코드)을 선택하면 종목별 승수와 입력 단위를 자동 적용하고, 현재가 입력만으로 1계약 필요금액과 원화 환산 금액을 계산합니다. 선택 상품의 만기 규칙과 현재 날짜 기준 가장 가까운 만기일·그다음 만기일도 표시하며, 수수료/목표가격 계산과 1계약 기준 손익 차트를 제공합니다.

## 파일 구성
- `option-calculator.html`: 앱 본체 (HTML/CSS/JS)
- `option_multipliers.md`: 승수 표(참고용). `PRODUCTS` 배열을 수정할 때 함께 업데이트하세요.
- `tests/expiry.test.cjs`: 상품별 만기 규칙과 날짜 경계 회귀 테스트
- `README.md`

## 실행 방법

### 1) 바로 열기
- `option-calculator.html`를 브라우저로 열어 사용합니다.

### 2) 환율 자동 불러오기를 쓰려면(권장)
브라우저 보안 정책에 따라 `file://`로 열었을 때 외부 `fetch()`가 막힐 수 있어 로컬 서버로 여는 것을 권장합니다.

- `python -m http.server 8000`
- `http://localhost:8000/option-calculator.html`

## 테스트

별도 패키지 설치 없이 Node.js 내장 테스트 러너로 실행합니다.

- `node --test .\tests\expiry.test.cjs`

## 주요 기능
- 자산군별 종목 드롭다운
- 종목별 승수/입력 단위 자동 적용
- 선택 상품의 만기 규칙과 가장 가까운 만기일 2개 표시
- 국내 지수(KOSPI200/KOSPI200 미니/KOSDAQ150) 지원
- 현재가 입력 → 1계약 필요금액 및 KRW 환산
- 환율 자동 불러오기 + 6시간 캐시
- KRW 상품은 환율 적용 없이 원화로 계산
- 기본값 저장(localStorage)
- 수수료 자동 적용(국내 0.15%, 기타 2.49 통화)
- 수수료/목표가격 계산 및 손익 차트(Chart.js)

## 만기 일정

선택한 상품에 대해 다음 정보를 표시합니다.

- 정규 만기 규칙(규칙적인 상품은 매월 몇째 주인지 포함)
- 현재 날짜부터 가장 가까운 만기일
- 그다음 만기일
- 한국시간 기준 시각과 D-day, 날짜가 다를 때의 거래소 현지 기준일
- 적용한 표준물 종류와 공식 규정·거래 달력 링크

화면의 기준 시각과 D-day는 한국시간을 사용합니다. 가장 가까운 만기를 고르는 판정과 표시되는 옵션 최종거래일은 거래소가 공시한 현지 거래일을 유지하며, 한국과 거래소의 날짜가 다를 때만 거래소 현지 기준일을 함께 표시합니다. 한국은 다음 날이지만 거래소가 아직 만기 당일인 경계에서는 `현지 D-DAY`로 표시해 만기를 조기에 제외하지 않습니다. 페이지를 계속 열어둔 경우 한국시간과 거래소 현지 날짜가 바뀌면 자동으로 갱신합니다.

표준 월물·분기물 또는 별도로 정의된 주간물만 계산하므로, 거래소가 임시로 상장한 시리즈나 상품별로 다른 위클리·일일물은 포함하지 않습니다. 미국 시장은 2026년 말, KRX·HKEX는 2027년 말의 등록된 휴장일 범위를 벗어나면 화면에 규칙 기반 `예상`임을 표시합니다.

### 상품별 적용 기준

- CME 통화 옵션(OADU/OEUU/OGBU/OJPU): 표준 월물, 결제월 셋째 수요일 직전의 두 번째 금요일
- CBOT 미국채 옵션(OZT/OZF/OZN/OZB): 표준 월물, 결제월 직전 달의 마지막 영업일보다 최소 2영업일 앞선 마지막 금요일(월말 직전 금요일 휴일 예외 적용)
- CME 주가지수 옵션(OES/ONQ): 표준 분기물, 3·6·9·12월 셋째 금요일
- CME S&P 500 Weekly(OES1~OES4): 매월 첫째~넷째 금요일 주간물(다섯째 금요일/EOM 시리즈 제외)
- HKEX HSI/HSCEI 옵션(OHSI/OHHI): 표준 월물, 결제월 두 번째 마지막 거래일
- KRX 지수·개별주식 옵션(KOSPI200/KOSPI200M/KOSDAQ150/KR_STOCK): 표준 월물, 결제월 둘째 목요일
- 미국 개별주식 옵션(US_STOCK): 종목이 지정되지 않은 공통 항목이므로 표준 월물 셋째 금요일만 계산
- COMEX 금·은 옵션(OGC/OSI): 표준 월물, 결제월 직전 달의 네 번째 마지막 영업일(금요일·휴장일 인접 시 조기 종료 규칙 적용)
- NYMEX WTI 옵션(OCL): 표준 월물, 기초 CL 선물 최종거래일보다 3영업일 앞선 날
- NYMEX 천연가스 옵션(ONG): 표준 월물, 기초 NG 선물 최종거래일보다 1영업일 앞선 날
- CBOT 농산물 옵션(OZC/OZS/OZM/OZW): 표준 월물, 결제월 직전 달의 마지막 영업일보다 최소 2영업일 앞선 마지막 금요일

휴장일이 규칙일과 겹치면 상품별 거래소 규정에 따라 앞당겨질 수 있습니다. 앱의 날짜는 일정 확인을 돕기 위한 값이며, 실시간 상장 종목 조회나 주문 가능 여부 확인 기능은 아닙니다.

### 삼성증권 HTS 사용 시 주의

이 문서와 화면의 상품 코드는 계산기 내부 식별·참고용이며 삼성증권 HTS의 실제 주문 종목코드와 다를 수 있습니다. 주문 전에는 HTS에서 다음 항목을 최종 확인하세요.

- 실제 상장된 월물·주간물과 종목코드
- HTS에 표시되는 최종거래일·만기일
- 주문 마감 시각, 만기일 조기 마감 및 휴장일 변경
- 만기 전 반대매매·자동청산 등 증권사별 처리 기준

특히 `US_STOCK`은 기초 종목에 따라 위클리 상장 여부가 달라 앱에서는 정규 월물만 표시합니다. 화면의 계산 날짜와 삼성증권 HTS가 다르면 HTS 표시와 거래소 최신 공지를 우선하세요.

## 입력 규칙

### 채권(미국채 2/5/10/30년)
32분할 입력 지원:

- `110'16` → 110 + 16/32
- `110'16+` → 110 + 16.5/32
- `110-16` → 110 + 16/32 (레거시)
- `110 16/32` → 110 + 16/32
- `110.5` → 소수 입력도 허용

### 농산물(옥수수/대두/대두박/소맥)
입력 단위는 `￠/부셸`(센트/부셸)로 가정합니다.

- `450.25` → 소수 입력
- `450'2` → 450 + 2/8
- `450'25` → 450 + 25/100
- `450'250` → 450 + 250/1000
- `450 2/8` → 분수 입력

### 미국 개별주식 옵션
대부분 1계약이 100주 기준입니다.

- 프리미엄 `1.23` → 1계약 $123

## 환율 자동 불러오기
- 버튼: “환율 자동 불러오기”
- 대상 통화: USD/HKD 등
- KRW 상품은 환율 입력/조회 없음
- 캐시: 로컬 저장 + TTL 6시간
- 사용 API (순차 fallback):
  - `https://api.frankfurter.app/`
  - `https://open.er-api.com/`

> 외부 서비스 가용성/정책에 따라 실패할 수 있으며, 실패 시 수동 입력 가능합니다.
